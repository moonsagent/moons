what you get

the website, CLI, library, local dashboard and MCP server all run on the same core. public DexScreener data, GeckoTerminal candles for the quote price.

flow back

buy-side volume per pair, vol x buys / (buys + sells), summed and compared with your token's market cap. always labelled as an estimate.

health score

0 to 100 from six parts: breadth, flow, diversification, growth, depth and buy pressure. every formula is in the README.

compare

moons compare A B puts up to 5 tokens side by side and marks who leads each number.

history

--history file.json keeps snapshots, so deltas survive restarts. moons history prints growth over time.

alerts

new pairs and threshold crossings to Discord webhooks and Telegram, plus a JSON payload for your own bots.

graph and dashboard

--graph out.html draws your token with its moons around it. moons ui runs a local dashboard that refreshes itself.

how the score works

six parts, rounded sum out of 100. 70 and up is strong, 40 to 69 moderate, under 40 weak.

PartMaxFormula
Breadth20active pairs (24h volume ≥ $1K), log scale, full at 50
Flow25estimated 24h flow, log scale, full at $1M
Diversification201 minus the HHI of volume shares
Growth15pairs created in 7 days, full at 10
Depth10share of pairs with liquidity ≥ $10K
Buy pressure1040% buys scores 0, 60% or more scores full

faq

Is the flow figure exact?

No. It approximates the USD value of buys in pairs quoted in your token from 24h volume and buy and sell counts, assuming equal average trade size. Use it to compare ecosystems and follow direction over time.

Which chains are supported?

Any chain DexScreener indexes. Solana is the default; pass --chain base, --chain bsc and so on. EVM addresses match case-insensitively.

Do I need an API key or an account?

No. moons uses public, documented DexScreener and GeckoTerminal endpoints, with retries, backoff and a short in-memory cache.

Where does my data go?

Nowhere except the API calls and the alert targets you configure. History stays in the local JSON file you name.

Does the website send my data anywhere?

No server in between. Your browser calls the public DexScreener API for pools and GeckoTerminal for the quote price line, and computes everything locally with the same code as the CLI.

Why does a big token show few or no pairs?

DexScreener returns up to 30 pools per token, most liquid first. For a large token those are mostly its own pools against SOL or USDC, so smaller coins paired against it can fall off the list. Launchpad quote tokens and coins that other coins pair against show up best.

Can I use it as a library?

Yes. import { ecosystemReport } from 'moons-cli'. The README lists every export.
